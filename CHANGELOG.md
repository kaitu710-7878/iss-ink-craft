# Changelog / 変更履歴

All notable changes to **ISS Ink Craft** will be documented in this file.

## [1.0.0-release] - 2026-11-17

### English
- Initial release for Minecraft 1.20.1 (Forge).
- Added shapeless crafting table recipes for base Iron's Spells 'n Spellbooks ink compression (Uncommon, Rare, Epic, Legendary) matching Alchemist Cauldron material costs.
- Added optional Forbidden Tiers integration for Mythic Ink and Ancient Ink crafting table compression.
- Added optional Apotheosis integration to craft Common Ink from 1x `apotheosis:common_material` and 1x `minecraft:glass_bottle`.
- Added common configuration (`iss_ink_craft-common.toml`) with custom `iss_ink_craft:config` recipe condition to toggle each recipe group individually.
- Added English (`en_us.json`) and Japanese (`ja_jp.json`) localization and bilingual documentation.

### 日本語
- Minecraft 1.20.1 (Forge) 向けの初回リリース。
- Iron's Spells 'n Spellbooks の基本インク（Uncommon / Rare / Epic / Legendary）を醸造釜圧縮と同じ素材消費で作れる作業台不定形レシピを追加。
- Forbidden Tiers 導入時、追加ティアのインク（Mythic / Ancient）も作業台で圧縮できるオプション連携を追加。
- Apotheosis 導入時、最下級レアリティ素材（`apotheosis:common_material`）1個とガラス瓶1個からコモンインクを作れるオプション連携を追加。
- 各レシピグループの有効/無効を切り替えられる共通コンフィグ（`iss_ink_craft-common.toml`）とカスタムレシピ条件 `iss_ink_craft:config` を実装。
- 日英バイリンガル対応（`en_us.json` / `ja_jp.json` およびドキュメント類）を実装。
